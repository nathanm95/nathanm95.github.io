# Portfolio — Nathan Marchant

Static portfolio site. No build step — plain HTML/CSS/JS.

## Local preview

```bash
python3 -m http.server 8123
# open http://localhost:8123
```

## Deploying to GitHub Pages

1. Push this repo to GitHub (e.g. `nathan-marchant/portfolio` or `<username>.github.io` for a root-domain site).
2. In the repo settings, go to **Pages** → **Build and deployment** → **Source: Deploy from a branch** → select `main` / `root`.
3. The site will be live at `https://<username>.github.io/<repo>/` (or `https://<username>.github.io/` if using a `<username>.github.io` repo name).
